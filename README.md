# Language TranslatorApp

🌐 Language Translator App (Tkinter + GoogleTrans)

A simple GUI-based Language Translator application built using Python Tkinter and googletrans. This app allows users to translate text between multiple languages using Google Translate’s unofficial API.

📌 Features

🌍 Supports 100+ languages
🔄 Automatic source language detection
🖥️ User-friendly Tkinter GUI
📝 Scrollable text input and output areas
⚠️ Error handling with pop-up messages
🚀 One-click translation

🛠️ Technologies Used

Python 3
Tkinter – for GUI
googletrans – for language translation
ttk – for modern combo boxes

📂 Project Structure

Language-Translator/
│
├── translator.py        # Main application file
├── README.md            # Project documentation
└── requirements.txt     # Required libraries

Requirements

Make sure you have Python 3.7+ installed.
Install required libraries using:
pip install googletrans==4.0.0-rc1
⚠️ Note: Use googletrans 4.0.0-rc1 for best compatibility.

🧠 How It Works

Enter text in the left text box
Select the target language
Click the Translate button
The translated text appears in the right text box
The app automatically detects the source language.
